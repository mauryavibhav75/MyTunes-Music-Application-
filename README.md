Music Tune is a feature-rich music application designed to connect users through music and creativity. It allows users to share playlists with friends using a unique connection code, enabling seamless friend-to-friend interaction without complex setup.

The platform organizes songs based on user moods, making music discovery more personalized and engaging. Users can explore playlists shared by nearby friends and enjoy a collaborative listening experience.

A unique feature, MyTune, empowers talented singers to showcase their skills by uploading their own performances. It serves as an easy platform for emerging artists to create profiles and reach a wider audience.

Built using modern web technologies like HTML, CSS, React.js, and Node.js, with MongoDB as the database, Music Tune integrates external APIs to enhance functionality and deliver a smooth user experience.
